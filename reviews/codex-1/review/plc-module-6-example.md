Source: [Agentic PLC Design, Module 6](https://github.com/nikbearbrown/agentic-plc-design/blob/1f296d98e06a14f51c54eea36a60d74fe122dd07/modules/06-logic-you-can-read.md), pinned commit. This is an example of what the exercise assesses, not a claim about a learner or a site feature already built.

Scope: a documented blocker can satisfy the compile/run branch of Gate G4. Mark observable simulation evidence only when actual results are attached. A synthetic L5X fixture, optional real export, hardware operation, and PLC program authorship are distinct claims. Reading a rung is not writing an independent ladder program. Do not infer any learner result from the syllabus.
